# smart-buyer

让 AI 先学会判断产品好坏，再替你购物。它同时研究“优质产品为什么好”和“廉价劣质产品通常坏在哪里”，冻结选购标准后才搜索具体候选，核实 SKU、包装规格、真实价格、参数和社区口碑，最后给出可追溯的性价比排序。

## 为什么需要它

普通的 AI 购物推荐很容易出现四类问题：先看到商品再倒推推荐理由；把列表页小包装起售价当成目标 SKU 价格；拿几篇带货文章自创指标；只看优点，遗漏酸败、缩水、易坏、难维护等失败模式。

`smart-buyer` 的设计思路是先建立评价体系，再接触候选：

1. 正向轨研究性能、体验和耐用性的增益指标；
2. 独立负向轨研究廉价劣质产品的常见缺陷、抽检/召回、维修数据和偷工减料路径；
3. 区分真实缺陷、品类天然局限、个人偏好和未证实风险；
4. 冻结核心参数、底线、风险指标和性价比公式；
5. 搜索候选并核实具体 SKU、总规格、实际价格和一手参数；
6. 去爱好者社区验证真实讨论，最后排序。

这个流程来自蓝牙耳机、油面筋、响铃卷等实际选购任务中的反复校正。响铃卷案例中，负向轨额外发现了油脂新鲜度、包装受潮、碎损和短时涮煮表现等只看蛋白质单价会漏掉的问题。

## 核心能力

- **正反双轨设标**：正向品质研究与负向失败模式研究相互隔离，减少围绕预设答案找证据。
- **反软文启发式**：只有单篇指南提出、又找不到原始依据的指标不能成为硬门槛；多篇文章转述同一来源只算一条证据。
- **风险分类**：不把品类天然限制或个人偏好误判成质量缺陷，也不凭理论风险给具体产品定罪。
- **SKU 与价格归一化**：记录具体 SKU、包装规格、总净含量、运费和优惠条件，统一换算后再比较，避免小包装引流价污染排序。
- **数据溯源分级**：优先使用官方规格、实际包装标签和监管/标准数据；追不到原始出处的数字明确标为未核实。
- **社区验证自包含**：不依赖其他 Skill；区分社区讨论与电商订单评价，逐帖核实回复数、长期反馈、反驳和竞品对比。
- **风险可见**：每个推荐都展示风险核对结果和到货验收建议，不让前期调研消失在最终报告里。
- **诚实降级**：负向证据或社区讨论不足时明确说明，不降低标准凑数。

## 使用示例

- “帮我挑一个 500 元以内的蓝牙耳机。”
- “哪款响铃卷的蛋白质性价比高，同时别有旧油味？”
- “A 和 B 两款机械键盘选哪个？”
- “给父母买一台洗衣机，优先耐用和维修方便。”

Agent 会先说明评价标准和证据，再列候选；不会只给一份没有来源的商品清单。

## 输出内容

每份完整报告包括：

- 核心参数、底线和主要失败模式；
- 推荐产品的具体 SKU 与价格口径；
- 参数核实状态和性价比计算过程；
- 风险核对与到货验收建议；
- 社区讨论来源、回复数、共识和争议；
- 不推荐候选及具体原因；
- 当前价格的核验时间与数据局限。

## 方法边界

- 社区热度不等于产品质量，只是证明存在可供核验的真实讨论。
- 回复为零的帖子会被排除，但不会因此直接断言它是广告。
- 失败模式研究决定“检查什么”，不能证明某个候选已经有该缺陷。
- 价格、库存和促销随时间变化，最终下单前仍应核对目标 SKU。
- 医疗、安全、食品法规等高风险判断应优先采用监管和标准资料，必要时寻求专业意见。
